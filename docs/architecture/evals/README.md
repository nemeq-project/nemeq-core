## Порядок v1

1. `L0` — тесты ядра: 17 инвариантов + мутанты. Приёмка: 100% критических мутантов, ≥90% автогенерируемых по классу.
2. `L1` — 5 сценариев жизненного цикла.
3. `L2` — паспорт модели (10 заданий × 3 повтора).
4. `L3` — пилот 20 задач × 3 попытки, **только сигнал**, без рейтингов; known-groups обязательны.
5. `L4` — 10 задач × 3 модели; β и effective votes — сигнал; решение о совете отложено.
6. `L6` — 10 инъекций + 5 exfil + PII-канарейка.
7. `L7` — validity ledger с первого дня.

## Правила, которые нельзя нарушать

- Первичная метрика — `accepted rate` по **исполняемым** гейтам; рубрика и судья вторичны.
- `false-done` считается rule-based; заявленный успех без гейта = провал.
- Рубрика **не** передаётся агенту во входе.
- Единица вывода — задача; попытки не увеличивают n.
- `pass^k` — только при `n ≥ k`.
- Пороги и правило действия фиксируются в decision record **до** прогона.
- Канарейка не должна встречаться в памяти, промптах и выходах.
